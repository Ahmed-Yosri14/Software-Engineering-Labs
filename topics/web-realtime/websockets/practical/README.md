# WebSocket Practical Track

This directory contains the hands-on WebSocket labs.

The goal is to build the application in levels, so each step teaches one new idea without hiding too much behind abstractions.

## Levels

| Level | Directory | Focus |
| --- | --- | --- |
| 1 | [level-01-foundations](level-01-foundations) | Open a WebSocket connection, send a message, receive a response |
| 2 | [level-02-chat-notifications](level-02-chat-notifications) | Multiple clients, connection manager, broadcast messages, join/leave notifications |
| 3 | `level-03-production-concerns` | Authentication, validation, heartbeats, reconnect behavior, and scaling notes |

## Current Rule

Do not jump ahead. Each level should be understandable before adding the next one.
